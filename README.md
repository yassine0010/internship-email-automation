# Automatic Internship Email Sender

A Python-based automation tool designed to streamline the bulky manual process of applying for internships. It reads contact information from a CSV file, cleans the data, filters out already-contacted companies, and automatically sends personalized application emails with your CV attached.

## 📁 Project Structure

* **`clean_data.py`**: Cleans raw data from `Export.csv` (e.g., fixing formatting issues in names and extracting valid emails) and saves the output to `Export_cleaned.csv`.
* **`filter_sent.py`**: A utility script to filter out recruiters or companies you have already contacted, outputting the remaining targets to `Export_cleaned_remaining.csv`.
* **`send_emails.py`**: The main execution script. It iterates through the cleaned list and sends personalized emails (inserting the company/recruiter name dynamically) attaching your CV.
* **`test_emails.py`**: A testing script to send a sample email to yourself first. Use this to verify email formatting, spelling, and attachments before blasting real recruiters.
* **`Export.csv`**: Your raw input data containing a list of target companies and contact info (you must provide/populate this).
* **`Export_cleaned.csv`**: Autogenerated data after running the cleaning script.
* **`Export_cleaned_remaining.csv`**: Autogenerated list of pending targets after filtering out previously sent emails.

## 🚀 How to Use & Customize (For Anyone!)

This project is built so anyone can clone this repository and adapt it for their own internship/job hunt. You just need to modify your personal details inside the scripts.

### 1. Prerequisites
Make sure you have Python installed. You will likely need to install the `pandas` library used for data manipulation:
```bash
pip install pandas
```

### 2. Prepare Your CSV Data
Fill `Export.csv` with your scraped or manual list of companies, contact names, and email addresses. Ensure your column names match the ones expected in the `clean_data.py` script.

### 3. Customize Your Profile & Email Content
You will need to open `send_emails.py` (and `test_emails.py`) to update the specific variables to match your profile:

* **Your Email Credentials**: At the top of the scripts, find these variables (or similar) and input your details. *(Note: If using Gmail with 2-Factor Authentication, you must generate an "App Password".)*
  ```python
  EMAIL_ADDRESS = "your.email@gmail.com"
  EMAIL_PASSWORD = "your_app_password"
  ```
* **The Email Subject & Body**: Scroll down to the message formatting section in the scripts and modify the text inside the `subject` and `body` variables:
  * Change the **Job Preference**: Swap out the target role for your own (e.g., Software Engineering Intern).
  * Change the **Skills Section**: Highlight your framework knowledge, languages, or soft skills directly in the `body` string.
  * *Tip: Keep the dynamic f-string variables (like `{company_name}` or `{recruiter_name}`) intact so the email remains personalized for each row in your CSV!*

### 4. Provide Your CV
Place your resume document in the root folder of this project (e.g., `Your_Name_CV.pdf`). Open `send_emails.py` and update the attachment filename to exactly match your resume's filename.

### 5. Run the Automation Pipeline

Execute the scripts via your terminal in this order:

```bash
# Step 1: Clean the messy raw data
python clean_data.py

# Step 2: (Optional) If you've run this before, filter out people you've already emailed
python filter_sent.py

# Step 3: Crucial - Test the email text and attachment on yourself!
python test_emails.py

# Step 4: Let it fly. Send the real emails to the filtered list.
python send_emails.py
```

## ⚠️ Important Considerations
* **Email Limits**: Be aware of your email provider's daily sending limits (standard Gmail accounts limit you to around 500 emails/day).
* **Security**: **NEVER** commit or upload your actual email passwords to a public GitHub repository. Use environment variables (`.env`) or make sure your repository is strictly Private.
